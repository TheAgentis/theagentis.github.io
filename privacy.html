Privacy Policy

Applies to: Shorts Uploader and this website. Last updated: 14 October 2026.

What Shorts Uploader is

Shorts Uploader is a private desktop tool used only by the owner of the YouTube channel The Simulation Files (@SimulationFilesHQ) to upload that channel's own videos. It is not available to the public.

Use of YouTube API Services

Shorts Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

Shorts Uploader requests a single permission: youtube.upload, which allows it to upload videos to the signed-in channel. It does not read, collect or analyze any other YouTube or Google account data, such as videos, comments, subscribers, viewing history, contacts or email.

How data is used and stored

  • The only data the tool handles is the sign-in token Google issues after the channel owner approves access. It is used solely to upload the owner's own videos.
  • That token is stored only on the channel owner's own computer. It is never sent to any server other than Google's.
  • No data is sold, shared with third parties, or used for advertising or analytics.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Deleting the token file from the owner's computer removes all stored data. Because nothing is stored anywhere else, nothing further needs to be deleted.

This website

This website uses no cookies, analytics or tracking, and collects no information about visitors.
